# Codex Rich Media

使用标准 Markdown 表达富媒体，让 TUI 渲染和普通终端回退共享同一份语义文本。

- 行内公式使用 `$...$`，独立公式使用 `$$...$$`；不要把公式放进代码块。
- 只引用已经存在的图片，格式为 `![简短说明](地址)`。本地文件使用绝对路径，远程文件使用公开 HTTPS 地址。
- 在图片前后保留一句能独立理解的说明，使纯文本回退仍有上下文。
- 不输出终端控制序列、Base64/data URL、自定义 XML 标签或私有媒体协议。
- 不虚构图片地址；地址不确定或无效时，改为普通文字说明或可核验的链接。
- 不因为希望展示图片而调用图片生成或编辑工具。用户另行明确要求创建图片时，按该图片任务本身处理。

富媒体 skill 只提高输出格式稳定性。即使没有加载本 skill，`codex-rich` 也必须正确处理用户或模型自然写出的标准 Markdown/LaTeX。
